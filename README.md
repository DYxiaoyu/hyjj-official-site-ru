# 汇盈聚金官网

这是汇盈聚金企业官网的静态站点文件，可直接部署到 Render Static Site。

## Render 设置建议

- Service type: Static Site
- Publish directory: `.`
- Build command: 留空
- Custom domain: `www.hyjjls.cn`

页面入口为 `index.html`，关于我们页面为 `about.html`。
